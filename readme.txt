### Organisation of the repository

There are 2 programs in this repository.


### 1. Oscillations_detection_numax.py: description in readme_Oscillations_detection_numax.txt

This program takes as an input the file spectre_*.txt and produces as outputs the plots  Smoothed_spectrum_fit_KIC_*.pdf and Spectrum_with_nu_max_KIC_*.pdf.


### 2. Oscillations_detection_Dnu.py: description in readme_Oscillations_detection_Dnu.txt

This program takes as an input the file spectre_*.txt and produces as outputs the plots Windowed_spectrum_KIC_*.pdf, EACF_signal_KIC_*.pdf and Windowed_spectrum_KIC_*.pdf.


### Installation: with anaconda

git clone https://github.com/cgehan-astro/ Postdoc_Portugal_oscillations_detection.git
cd  Postdoc_Portugal_oscillations_detection
conda env create -f environment.yml
